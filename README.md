# Мобидик — новые iPhone, СахаЭкспоЦентр

Отдельный фид новых телефонов для Юлы: https://raw.githubusercontent.com/mobideektel-eng/youla-new-feed-sec/main/feed-sec.xml . Существующий фид б/у телефонов `mobideektel-eng/youla-feed/main/feed-sec.xml` и фид ТелМарт не изменялись.

Текущая версия содержит **12 моделей**. По просьбе владельца 23.11.2026 исключены iPhone 15 Plus, iPhone 16 Plus, iPhone 16e и iPhone 17e; генератор также настроен не возвращать их при следующем обновлении прайса. ID, цены и изображения остальных объявлений сохранены.

Источник цен — последний доступный полный прайс price-bot от 18.11.2026. Для каждой оставшейся модели выбрана одна конфигурация с минимальной ценой и одно изображение. Это разовая выгрузка, автоматическое обновление прайса пока не подключено.

Оформление «Мобидик»: исходный логотип владельца, выбранный им вариант «белая витрина». Визуалы телефонов — иллюстрации; это не фотографии конкретных товаров.
