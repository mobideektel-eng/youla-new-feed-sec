# Мобидик — новые iPhone, СахаЭкспоЦентр

Отдельный фид новых телефонов для Юлы: `feed-sec.xml`. Не связан с фидом б/у телефонов `mobideektel-eng/youla-feed/main/feed-sec.xml` и фидом ТелМарт.

Публичный адрес фида: https://raw.githubusercontent.com/mobideektel-eng/youla-new-feed-sec/main/feed-sec.xml

Выгрузка содержит 16 моделей по последнему доступному полному прайсу price-bot от 18.11.2026. Для каждой модели выбрана одна конфигурация с минимальной ценой. Это разовая выгрузка; автоматическое обновление прайса не подключено.

На каждое объявление приходится одно изображение карточки в оформлении «Мобидик». Использован предоставленный владельцем логотип. Визуалы телефонов — иллюстрации: 15 созданы ИИ, один взят по лицензии CC BY 4.0. Это не фото конкретных товаров.
